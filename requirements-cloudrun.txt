# ==============================================================================
# CLOUD RUN PRODUCTION REQUIREMENTS
#
# Derived from requirements-prod.txt with three deliberate removals. Each is
# justified by a grep of the source tree, not by guesswork:
#
#   torch + sentence-transformers  (~1.9 GB)
#       Only reachable via app/services/retrieval/embedding.py::_load_fallback(),
#       which is a lazy import behind a failed-Jina-probe branch. On Cloud Run we
#       want that branch to fail loudly rather than silently load 2 GB into a
#       container that must cold-start in seconds. Jina is the contract.
#
#   langchain-google-vertexai      (~120 MB)
#       Zero references in app/ or ui/. Dead weight.
#
#   langchain-nvidia-ai-endpoints  (~40 MB)
#       Zero references in app/ or ui/. Dead weight.
#
# Result: image drops from roughly 2 GB to roughly 400 MB, which is the single
# largest lever on Cloud Run cold-start latency.
#
# streamlit is KEPT: the UI runs from this same image with a different command.
# ==============================================================================
